# 音乐总谱编辑、移调与分谱出版准备平台

源提示词编号：12。支持多声部总谱、VexFlow 五线谱、音符与力度/连音/表情编辑、移调乐器、分谱提取与换页提示音、版本差异、评论锚点、撤销重做、打印和未保存恢复。

## 离线校订交接

「交接与候选」页把总谱、分谱、评论和出版候选接成可续作的交接过程：

- 声部长回传离线校订后，按音符标识与评论锚点同现行总谱三方比较：单边修改直接并入候选，两边都改过则保留双方内容等待处置，处置前不能并入。
- 同一册同时有多份回传时，先到者成为出版候选，后到内容留作冲突，不静默覆盖；前序候选处置完毕后到者自动晋升。
- 总谱音符、移调或评论每改一次，基线修订号递增，受影响的候选与换页提示立即失效并按新基线重算；已写盘的候选记录标记失效，可按新基线重写。
- 回传先写已交声部日志再写候选记录；写盘失败后从日志恢复，重试按提交标识幂等写入，不重复追加记录。
- 没有声部标识的旧稿按现有顺序回填标识并升级为 v2 结构，旧稿中的原出版版本并入版本列表仍可查回。
